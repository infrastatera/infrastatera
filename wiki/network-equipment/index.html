Wiki / Systems

Network equipment: switches, routers, SFPs and cellular

Verify the edition named in your contractNot yet verified against the current edition

In one sentence: network equipment lets every device in the field talk to the TMC, over fiber or cellular.

Main parts

ItemWhat it is for
Ethernet switchesConnect devices in the cabinet; managed, industrial-rated
Fiber switchesConnect the cabinet to the fiber network
SFP modulesPlug-in transceivers that connect a switch port to fiber
Cellular routersWireless link to the network where there is no fiber
AntennasCellular signal for the router
Patch cords and CAT6Connect equipment in the cabinet and to nearby devices

The models are usually named or specified in the Special Provisions: what they change and why they win; the plans include a network diagram.

Configuration

IP addresses, VLANs, management access and security settings from Caltrans's network plan. See Phase 8: Network and system configuration.

PM notes

  • Match SFPs to the fiber type, wavelength and distance; the wrong SFP is a common cause of a dead link.
  • Cellular routers need carrier service set up; confirm who provides the SIM and data plan.
  • Save every final configuration file for the closeout package. See Closeout package checklist.

Common mistakes / what Caltrans actually checks

  • Wrong SFP type for the fiber or distance.
  • No SIM or data plan when the router arrives.
  • Default passwords left on devices.
