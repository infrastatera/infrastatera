Glossary

BCDFGIOPRST
Ball in court
The person who must act next on an item, such as an RFI or a submittal; it moves automatically as the workflow advances. Read more
Budget code
A code in Procore's work breakdown structure combining a cost code and a cost type, used for budget and cost lines. Read more
Change event
A record of anything that may change a project's scope or cost, created before it becomes a change order. Read more
Collaborator
An outside company, such as a subcontractor, invited to work in your Procore project with limited access. Read more
Commitment
A subcontract or purchase order in Procore: what you have agreed to pay a sub or supplier. Read more
Commitment change order
A change to a subcontract or purchase order. Read more
Cost code
A code that groups costs by work activity; on Caltrans jobs it usually follows the bid items. Read more
Daily Log
Procore's tool for the day's record: manpower, equipment, weather, notes, delays, photos and more. Read more
Distribution list
The people who receive notifications about an item without being responsible for it. Read more
Drawing area
A way to keep separate sets of drawings in one project when sheet numbers repeat. Read more
Final approver
The person with authority to close a punch item. Read more
Granular permission
An extra permission that allows a specific action on a tool beyond the general permission level. Read more
Inspection
A checklist filled on site from a template, with items answered as pass, fail or not applicable. Read more
Observation
An issue assigned to someone to fix, often created from a failed inspection item. Read more
OCROptical character recognition
Reading text from a PDF image; Procore uses it to name and number drawing sheets and split spec books. Read more
Official response
The response chosen by the RFI manager as the answer to an RFI. Read more
Permissions template
A saved set of permission levels for each tool, assigned to users by role. Read more
Potential change order
In two- and three-tier change workflows, a step before a change order is final. Read more
Prime contract
The contract between the owner and the general contractor; in Procore, the tool that holds it and its schedule of values. Read more
Prime contract change order
A change to the contract with the owner; on Caltrans jobs it records a Contract Change Order. Read more
Project archive
Procore's tool for exporting project records and documents into an organized download (formerly Data Extracts). Read more
Punch item manager
The person who oversees a punch item, assigns it and forwards it for final approval. Read more
RFI manager
The person responsible for an RFI through its life, who picks the official response and closes it. Read more
RFQRequest for quote
A request sent from a change event to a sub or supplier to price their part of a change. Read more
Schedule of values
The list of line items and amounts a contract is billed against. Read more
Submittal manager
The person who owns a submittal and receives it back when the workflow ends. Read more
Submittal package
A group of related submittals reviewed together. Read more
Submittal workflow
The ordered steps of submitters and approvers a submittal goes through. Read more
Tool
In Procore, a module that handles one kind of record, such as RFIs or Drawings, at the company or project level. Read more
