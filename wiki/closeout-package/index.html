Closeout package checklist

Not yet verified against the current edition

In one sentence: the closeout package is the proof of what you built, and the job isn't finished until it is delivered and accepted.

Checklist

DocumentNotes
As-built plansEvery change marked, with locations and depths
Fiber splice diagramsMatching the field and the labels
Test resultsElectrical, fiber and functional tests
Material certificationsCertificates of compliance for materials that need them
Battery certificationsModel, install date, warranty
Concrete ticketsFor foundations and encasements
Warranty documentsWith start dates
Equipment manualsOne set per device type, or as the contract requires
Configuration filesFinal switch, router and device settings
Serial number listBy location
Final CPM scheduleUpdated to actual dates
Acceptance recordsPunch list closed, sign-offs

Final quantities

Agree on the final measured quantity of every unit-price item. Daily reports and measurements support them. See Daily reports and documentation.

PM notes

Build the package from day one. File certificates with each submittal, tests as they are run, as-builts as changes happen. See Phase 12: Project closeout and delivery.

Common mistakes / what Caltrans actually checks

  • As-builts drawn from memory at the end.
  • Manuals thrown away with packaging.
  • Warranty start dates not agreed.
